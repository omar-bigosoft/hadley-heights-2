# Hadley Heights 2

A cinematic, scroll-driven digital experience for Hadley Heights 2 by LEOS Developments. Built with Next.js, Tailwind CSS, GSAP, and Lenis.

## Development

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) to view the experience.

## Deployment

Pushes to `main` are exported as a static site and deployed automatically through GitHub Pages.
